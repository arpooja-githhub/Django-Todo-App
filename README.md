# 📝 Django Todo App

A simple and clean Todo List web application built using Django.  
Users can add tasks, mark them as completed, undo them, and delete tasks.

---

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🔄 Mark tasks as undone
- 🗑️ Delete tasks
- ✏️ Edit tasks
- 📂 Separate sections for Pending and Completed tasks

---

## 🛠️ Tech Stack

- Backend: Django (Python)
- Frontend: HTML, CSS, Bootstrap
